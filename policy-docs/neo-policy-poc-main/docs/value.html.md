# value

The **<value>** provides values for
enclosing [<if-src-attr>](if-src-attr.html) and
[<if-dest-attr>](if-dest-attr.html) when
[<arg-dn>](arg-dn.html) or [<arg-assocation>](arg-assocation.html)
is used to specify the object.
