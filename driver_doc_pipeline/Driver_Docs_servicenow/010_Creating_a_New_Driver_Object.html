3.0 Creating a New Driver Object

You install the ServiceNow driver files on the server where you want to run the driver, and then proceed to create the driver in the Identity Vault. You create the ServiceNow driver by installing the driver packages or importing the basic driver configuration file and then modifying the driver configuration to suit your environment.
