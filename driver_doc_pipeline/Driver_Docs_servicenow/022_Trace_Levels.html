B.0 Trace Levels

The driver supports the following trace levels:

Table B-1 Supported Trace Levels

Level

Description

0

No debugging

1-2

Identity Manager messages. Higher trace levels provide more detail.

3

Previous level plus driver parameters, Remote Loader, driver shim, and driver connection messages

4-5

Previous level plus Remote Loader, driver, driver shim, and driver connection messages, driver parameters, driver security, driver schema, request and response XML
