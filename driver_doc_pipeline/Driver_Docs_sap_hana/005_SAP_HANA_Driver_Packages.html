2.1 SAP HANA Driver Packages

The following packages are available for this driver:

Name

Package Name

Description

SAP HANA Base Configuration

SAPHANABASE

This package contains the base configuration. It is a mandatory package.

SAP HANA Default Configuration

SAPHANADFG

These packages contain the default configuration information for the SAP HANA. Always leave this package selected.

SAP HANA Driver Entitlements Package Configuration

SAPHANAENT

This package is used for synchronizing entitlements.

SAP HANA Driver Group and Role Synchronization

SAPHANAGNR

This package is used for synchronizing roles and groups.

SAP HANA Driver Password Synchronization

SAPHANAPSYNC

This package is used for password synchronizing
