A.0 Driver Properties

This section provides information about the Driver Configuration and Global Configuration Values properties for the SAP HANA driver. These are the only unique properties for drivers. All other driver properties (Named Password, Engine Control Values, Log Level, and so forth) are common to all drivers. Refer to Driver Properties in the NetIQ Identity Manager Driver Administration Guide for information about the common properties.

The information is presented from the viewpoint of Identity Console. If a field is different in Designer, it is marked with a Designer icon.
