1.0 Understanding the SAP HANA Driver

The Identity Manager Driver for SAP HANA (High-performance Analytic Application) synchronizes data between Identity Vault and SAP HANA database. SAP HANA is a single suite that combines the HANA Database, Data Modeling, HANA Administration, and Data Provisioning. The driver supports the Subscriber and Publisher channels, uses filters to control objects and attributes, and uses policies to control data.

SAP HANA Cloud provides a single place to access, store, and process all enterprise data in real time. SAP HANA Cloud is a single database as a service (DBaaS) foundation. It is a cloud-native platform that reduces the complexity of multi-cloud or hybrid system landscapes. SAP HANA Cloud provides all of the advanced SAP HANA technologies for multi-model data processing in-memory. The SAP HANA Cloud allows you to consume the SAP HANA database from applications running on SAP Business Technology Platform, as well as from applications running on premise or other cloud services using the standard SAP HANA clients. The SAP HANA Cloud provides simplified data access to connect all your information without the need to have all data loaded into a single storage solution.

Every SAP HANA Cloud, SAP HANA database instance is equivalent to a single tenant database. For multiple databases, create multiple SAP HANA database instances. Using SAP HANA Cloud Central or the command-line interface, you can create and manage SAP HANA Cloud instances in your sub-account.
