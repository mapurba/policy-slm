4.0 Creating a New Driver Object

After the PeopleSoft driver files are installed on the server where you want to run the driver (see Section 2.0, Installing the Driver Files) and you have configured your PeopleSoft environment (see Section 3.0, Configuring Your PeopleSoft Environment), you can create the driver in the Identity Vault. You do so by installing the driver packages and then modifying the driver configuration to suit your environment. The following sections provide instructions:

  • Creating a PeopleSoft Account

  • Creating the Driver Object in Designer

  • Deploying, Starting and Activating the Driver

  • Adding Packages to an Existing Driver
