1.2 Prerequisites

  • The appropriate version of the PeopleTools psjoa.jar client to match the PeopleTools version of the target PeopleSoft Application Server.

  • A .jar file containing the compiled Java Component Interface APIs for the desired integration component. For the default PSA components, the file containing the interfaces is named dirxmlcomps.jar. For more information on creating Component Interface APIs, refer to Section 6.0, Customizing the Driver.
