4.0 Creating a New Driver Object

After the WorkOrder driver files are installed on the server where you want to run the driver (see Section 3.0, Installing Driver Files), you can create the driver in the Identity Vault. You do so by installing the driver packages and then modifying the driver configuration to suit your environment. The following sections provide instructions:

  • Creating the WorkOrder Container in the Identity Vault

  • Creating the Driver Object in Designer

  • Activating the Driver

  • Adding Packages to an Existing Driver
