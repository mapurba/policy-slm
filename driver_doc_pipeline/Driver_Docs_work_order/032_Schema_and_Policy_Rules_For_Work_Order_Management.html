C.0 Schema and Policy Rules For Work Order Management

As part of the installation of the WorkOrder driver, NetIQ eDirectory is extended to include two new object classes. These objects allow the driver to connect to the Identity Vault correctly, perform work orders, and create a process log with the work order status.

You can use Identity Console to create or view these objects in the Identity Vault. See Section 6.0, Customizing the Driver.

  • DirXML-WorkToDo Object
