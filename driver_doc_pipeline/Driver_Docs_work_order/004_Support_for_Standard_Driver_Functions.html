1.3 Support for Standard Driver Functions

There are several functions that most Identity Manager drivers support. The following list explains whether or not the WorkOrder driver supports these standard functions.

Local Platforms: The WorkOrder driver can run on the same platforms as the Identity Manager engine. See Implementation Checklist in the NetIQ Identity Manager Setup Guide for Linux or Planning Your Installation in the NetIQ Identity Manager Setup Guide for Windows.

Remote Platforms: The WorkOrder driver works on all the platforms supported by the RemoteLoader. For System Requirements for Identity Manager Engine, Remote Loader, and Identity Console, see Technical Information for Identity Manager page.

Entitlements: The WorkOrder driver does not support Entitlements.

Password Synchronization Support: The WorkOrder driver does not support password synchronization.

Synchronized Objects: The WorkOrder driver only processes events that pertain to work orders. It does not synchronize other objects and attributes within the Identity Vault.
