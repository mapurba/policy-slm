2.0 Installing the Driver Files

You must install Salesforce.com driver on a server that has HTTP access to the Salesforce.com Web service with which the driver will communicate. The Salesforce.com driver can be installed on multiple systems and platforms. To verify the system requirement list, see the NetIQ Identity Manager Technical Information website.
