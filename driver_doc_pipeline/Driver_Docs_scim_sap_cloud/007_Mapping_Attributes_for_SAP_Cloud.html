1.6 Mapping Attributes for SAP Cloud

The attributes of Identity Manager and SAP Cloud must be mapped as per the schema mapping.

For more information, see Mapping Attributes for Identity Manager and Connected Application in the NetIQ SCIM Driver Implementation Guide.

After the schema is fetched from the SAP Cloud, the attributes of Identity Manager and SAP Cloud are mapped in the backend by default. If any changes are required, you can modify the attributes as required.
