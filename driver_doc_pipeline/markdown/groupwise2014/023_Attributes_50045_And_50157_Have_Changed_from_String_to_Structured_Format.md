# 8.1 Attributes 50045 And 50157 Have Changed from String to Structured Format

If you experience an error while attempting to set attribute 50045 or 50157, see [Converting String Attributes to Structured Attributes](modify-policies.html#b1ey3xc1). For more information about how GroupWise handles these attributes, see [GroupWise SDK: Administration REST API Guide](https://www.novell.com/documentation/groupwise2014/gwsdk_gwadminweb/data/bookinfo.html).
