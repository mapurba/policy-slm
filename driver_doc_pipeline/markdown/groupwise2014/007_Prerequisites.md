# 2.1 Prerequisites

* Identity Manager 4.6 or later.
* Designer 4.6 or later
* GroupWise 2014 SP1 or later, and GroupWise 18

*IMPORTANT:*Log in to the GroupWise Administration console and verify that the Identity Vault information is correctly linked with the GroupWise server. For more information, see [Associating Identity Vault with GroupWise System](create-driver-object-designer.html#b1d27cy6)
