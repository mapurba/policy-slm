# 3.0 Creating a New Driver Object

After the Oracle EBS driver files are installed on the server where you want to run the drivers (see [Section 2.0, Installing the Driver Files](installing-the-driver-files.html)), you can create each driver object in the Identity Vault. You do so by installing the driver packages and then modifying the driver configuration to suit your environment. The following sections provide instructions:

* [Creating the Driver Object in Designer](creating-the-driver-object-in-designer.html)
* [Activating the Driver](activating-the-driver.html)
* [Adding Packages to an Existing Driver](adding-packages-to-an-existing-driver.html)
