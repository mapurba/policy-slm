# 4.1 Supported Upgrade Paths

You can upgrade the drivers to the following versions:

* HR driver to 4.1.2 version
* User Management driver to 4.1.2 version
* TCA driver to 4.1.2 version

The latest versions of the drivers provide support for configuring Suite B communication between the Remote Loader and the Identity Manager engine. For more information, see [Authentication](driver-configuration.html#b4jzr84). For more information about Suite B, see [Suite B Cryptography](http://www.nsa.gov/ia/programs/suiteb_cryptography/index.shtml).
