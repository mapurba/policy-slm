# 1.1 Terminology

This section gives you essential information about terminology used with SAP and the SAP Portal driver.

*ABAP:*
Advanced Business Application Programming. A programming language designed for creating large-scale business applications.

*BAPI:*
Business APIs for the SAP business object types.

*CUA:*
Central User Administration.

*SPML:*
Service Provisioning Markup Language. An XML-based framework for managing the provisioning and allocation of identity information and system resources within and between organizations.

*UME:*
User Management Engine.
