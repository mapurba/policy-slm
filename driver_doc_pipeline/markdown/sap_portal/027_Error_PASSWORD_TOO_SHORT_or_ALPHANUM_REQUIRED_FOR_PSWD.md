# 9.4 Error PASSWORD\_TOO\_SHORT or ALPHANUM\_REQUIRED\_FOR\_PSWD

If a reset password does not comply with the SAP Portal Security Policy, these errors are visible in the DSTrace. This might happen when resetting a user’s password in the SAP Portal. The password must comply with your SAP Portal Security Policy for passwords. The default SAP Portal Security Policy requires alphanumeric passwords between 5 and 14 characters in length.
