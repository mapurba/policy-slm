# 3.0 Checklist for Enabling Identity Tracking

Use the following checklist to verify that you complete the following tasks in order to have a complete solution with the driver.

* Ensure that you have installed the software mentioned in [System Requirements](system-requirements.html).
* Determine where you want to install the driver shim. For more information, see [Section 4.0, Planning the Driver Shim Installation](planning-the-driver-shim-installation.html).
* Install the driver shim. For more information, see [Section 5.0, Installing the Driver Shim](installing-the-driver-shim.html).
* Create and configure the driver. For more information, see [Section 6.0, Creating and Configuring the Driver](creating-and-configuring-the-driver.html).
* Migrate the identity data to Sentinel For more information, see [Section 9.0, Migrating Data](migrating-data.html).
