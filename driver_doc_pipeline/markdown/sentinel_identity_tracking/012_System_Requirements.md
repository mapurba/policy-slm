# 4.1 System Requirements

You need the following software to integrate Identity Manager with Sentinel:

* Identity Manager 4.0.1 or later.

  For information about installing Identity Manager 4.0.1, see Identity Manager installation instructions for your version from the [documentation](https://www.netiq.com/documentation/) site.
* Designer for Identity Manager 4.0.1 or later.

  For information about installing Designer, see Designer installation instructions for your version from the [documentation](https://www.netiq.com/documentation/) site.
* Sentinel 7.0.1 or later.

  For information about installing Sentinel 7.0.1 or later, see Sentinel installation instructions for your version from the [documentation](https://www.netiq.com/documentation/) site.
