# 4.0 Creating New Fanout Driver

After the Fanout driver files are installed on the server where you want to run the driver object, you can create a driver object in the Identity Vault. Creating a driver object consists of installing the driver packages and then modifying the driver configuration to suit the environment.

* [Creating a Fanout Driver Object in Designer](how-to-create-jdbc-fan-out-driver-object-in-designer.html)
* [Activating the Driver](how-to-activate-jdbc-driver.html)
* [Adding Packages to an Existing Driver](how-to-add-packages-to-the-existing-jdbc-fan-out-driver.html)

You must install the Fanout components before configuring a new Fanout driver object. For more information, see [Section 2.0, Installing the Fanout Driver Components](install-jdbc-fanout-components.html).
