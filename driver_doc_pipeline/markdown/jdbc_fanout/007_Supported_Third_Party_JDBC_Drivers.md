# 1.6 Supported Third-Party JDBC Drivers

The Fanout driver supports the following third-party JDBC drivers:

* MySQL Connector/J
* Oracle Thin Client
* Oracle OCI
* jTDS

For more information, see [Third-Party JDBC Driver](../../jdbc/data/data-sync-components-for-identity-manager-jdbc-driver.html#ail8qxr) in the [NetIQ Identity Manager Driver for JDBC Implementation Guide](../../jdbc/data/netiq-identity-manager-driver-for-jdbc.html#netiq-identity-manager-driver-for-jdbc).
