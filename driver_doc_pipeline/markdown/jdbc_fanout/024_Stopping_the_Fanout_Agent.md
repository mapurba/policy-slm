# 3.5 Stopping the Fanout Agent

You can stop the Fanout agent by passing the stopAgent command in the command prompt.

To stop the Fanout Agent in the command prompt:

1. Open a command prompt.
2. Run the stopAgent command and pass the default configuration file name as a parameter inthe command.

   stopAgent –config <FanoutAgent Installation Location>/config/fanoutagent-config.properties <agent password>.

   The installation path will vary depending on the Fanout agent version you are running.
