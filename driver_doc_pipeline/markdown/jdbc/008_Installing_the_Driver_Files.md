# 2.1 Installing the Driver Files

You can install the JDBC driver files in the following ways:

* On a local machine: Install the JDBC driver files on the Identity Manager server and connect to the database by using the Provider URL (Connection Properties).
* On a remote machine: Install the JDBC driver files on the Remote Loader.

For information on installing the Identity Manager server or the Remote Loader, see [Considerations for Installing Identity Manager Engine Components and Remote Loader](../../../identity-manager-48/setup_linux/data/considerations-install-engine-components-remote-loader.html#considerations-install-engine-components-remote-loader) in the [NetIQ Identity Manager Setup Guide for Linux](../../../identity-manager-48/setup_linux/data/front.html#front) or [Planning to Install the Engine, Drivers, and Plug-ins](../../../identity-manager-48/setup_windows/data/planning-to-install-engine-drivers-plugins.html#planning-to-install-engine-drivers-plugins) in the.[NetIQ Identity Manager Setup Guide for Windows](../../../identity-manager-48/setup_windows/data/front.html#front).
