## 1.3.1 Generic JDBC Driver

The Identity Manager JDBC driver uses the JDBC interface to synchronize data and identities between an Identity Vault and relational databases.

The driver consists of the following jar files:

* JDBCShim.jar
* JDBCUtil.jar
* JDBCConfig.jar

In addition to these files, you need a third-party JDBC driver to communicate with every database.
