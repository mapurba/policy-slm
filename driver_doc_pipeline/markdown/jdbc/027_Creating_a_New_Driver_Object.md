# 5.0 Creating a New Driver Object

After the JDBC driver files are installed on the server where you want to run the driver object (see [Section 2.0, Installing the Driver Files](install-jdbc-driver-for-identity-manager.html)), you can create a driver object in the Identity Vault. You do so by installing the driver packages and then modifying the driver configuration to suit your environment. The following sections provide instructions:

* [Creating the Driver Object in Designer](how-to-create-a-driver-object-using-designer-for-jdbc-driver.html)
* [Activating the Driver](how-to-activate-jdbc-driver.html)
* [JDBC Driver Settings](modify-jdbc-driver-settings.html)
