# 13.2 Supported Databases

The following databases or database versions have been tested and are recommended for use with this product:

*Table 13-1* Supported Databases

| Database | Minor Version |
| IBM DB2 Universal Database (UDB) | 12.0 or later  11.0 or later |
| Informix Dynamic Server (IDS) | 11.0 or later |
| Microsoft SQL Server | 2016, 2017, 2019 and 2022 |
| MySQL | 8.x |
| Oracle | 19c, 21c, and 23c |
| Azure Database for PostgrSQL flexible servers | 14.4 |
| PostgreSQL | 17.0 or later  16.0 or later  15.0 or later  14.0 or later |
| Sybase Adaptive Server Enterprise (ASE) | 15.0 or later |
| MariaDB | 10.11 or later |

You can use the JDBC driver with other databases or database versions. However, NetIQ does not support them. To interoperate with the JDBC driver, a database must meet the following requirements:

* Support the SQL-92 entry level grammar.
* Be JDBC-accessible.
