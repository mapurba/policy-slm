# 7.1 What’s New

## 7.1.1 What’s New in Version 4.1.0.1

This version of the driver does not provide any new features.

## 7.1.2 What’s New in Version 4.1.0

This version of the driver provides the following features:

* Identity Manager 4.7 provides support for MapDB 3.0.5. To ensure that your driver works correctly with Identity Manager 4.7 engine, see [Working with MapDB 3.0.5](working-with-mapdb305.html).
* The driver now supports the Subscriber Service channel. This channel enables you to separately process the out-of-band queries without interrupting the normal flow of cached events. For example, the Subscriber Service channel can separately process code map refresh, data collection, and queries triggered from dxcmd. This helps to improve the performance of the driver. For more information, see [Improving Driver Performance Using Subscriber Service Channel](../../../identity-manager-48/driver_admin/data/t41hj9uznkpr.html#t41hj9uznkpr) in the [NetIQ Identity Manager Driver Administration Guide](../../../identity-manager-48/driver_admin/data/bktitle.html#bktitle).
