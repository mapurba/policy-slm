# 2.1 Checklist for Installing and Configuring the Driver

Use the following checklist to ensure that you complete all of the tasks required to set up and use the IGIM driver:

* Ensure that your environment meets the requirements for installing and configuring the IGIM driver. For more information, see [Planning to Install and Configure the Driver](planning-to-install-and-configure-netiq-igim-driver.html).
* Install the driver files on the Identity Manager engine or on a Remote Loader server. For more information, see [Installing the Driver Files](installing-the-netiq-idm-igim-driver-files.html).
* Ensure that you have the appropriate packages installed and imported for the driver. For more information, see [Importing the Current Driver Packages](creating-and-configuring-the-netiq-idm-igim-driver.html#importing-latest-driver-packages-for-netiq-idm-igim-driver).
* Configure the basic settings for the driver from Driver Parameters. For more information, see [Configuring the Driver Settings](creating-and-configuring-the-netiq-idm-igim-driver.html#configuring-the-netiq-igim-driver-settings).
* Assign appropriate rights to the driver object for reading and writing Identity Vault objects. For more information, see [Rights Needed by the Driver Object (for 1.1.0.0100 and later)](rights-needed-by-the-netiq-idm-igim-driver.html).
* For the version 1.1.0, assign appropriate rights to the driver object for reading and writing Identity Vault objects. For more information, see [Rights Needed by the Driver Object](t4pjaho1xd81.html).
* Deploy the driver to the Identity Vault. For more information, see [Deploying the Driver Object](deploying-the-netiq-idm-igim-driver.html).
* Start the driver. For more information, see [Starting the Driver](starting-the-netiq-idm-igim-driver.html).
