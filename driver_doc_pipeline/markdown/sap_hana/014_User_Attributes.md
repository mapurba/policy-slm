# 3.1 User Attributes

The below table lists user attributes.

*Table 3-1* Mapping of User Attributes

| SAP HANA Attribute Name | NDS-Name | Description |
| USER\_NAME | CN | Name of the user. |
| COMMENTS | Description | Description of the user. |
| USERGROUP\_NAME | Group Membership | Group to which the user belongs to. |
| USER\_MODE | employeeType | Employee type to which the user belongs to. |
| USER\_DEACTIVATED | Login Disabled | Specifies if the user is disabled or deactivated from login activities. |
| EMAIL ADDRESS | Internet EMail Address | E-mail address of the user. |
