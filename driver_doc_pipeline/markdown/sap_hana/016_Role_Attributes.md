# 3.3 Role Attributes

The below table lists Role attributes.

*Table 3-3* Mapping of Role Attributes

| SAP HANA Attribute Name | NDS-name | Description |
| ROLE\_NAME | CN | Role description |
| COMMENTS | sapHanaComments | Description of the role. |
| ROLE\_MODE | sapHanaRoleMode | Mode of the specified role. |
| ROLE\_SCHEMA\_NAME | sapHanaRoleSchemaName | Schema name to which the role belongs to. |
| ROLE\_GROUP\_NAME | sapHanaRoleGroupName | Group name to which the role belongs to. |
