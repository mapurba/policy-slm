# A.2 Performance

Ensure that indexes for the uidNumber and gidNumber attributes exist and are online.

To avoid assigning duplicate UID and GID numbers, the driver searches the respective subtrees specified during installation, or later by GCVs. For good performance, you must create indexes for uidNumber and gidNumber. For details, see [Step 4](bbexhtj.html#b3r6v2s).

For details about managing indexes, see the NetIQ eDirectory Administration Guide.
