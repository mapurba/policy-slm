# B.0 System and Error Messages

Components of the Identity Manager 4.8 driver for IBM i (i5/OS and OS/400) write messages to the driver shim job log to report operational status and problems. You can use the DSPJOBLOG command or IBM i Navigator to view the job log. For more information about the job log, see [The Job Log](b3xzdtn.html#b3xzhok). For detailed troubleshooting information, see [Section A.0, Troubleshooting](b3r8uai.html).

Each message begins with a code of 3-6 characters associated with the driver component that generated the message. Use this code to find message information quickly as follows:

* [CFG Messages](b48n3rd.html)
* [CHGLOG Messages](b48n3rj.html)
* [DOM Messages](b48n3rl.html)
* [DRVCOM Messages](b48n3rn.html)
* [HES Messages](b48n3rs.html)
* [LWS Messages](b48n3rw.html)
* [NET Messages](b48n3t5.html)
* [OAP Messages](b48n3th.html)
* [RDXML Messages](b48n3tn.html)
