# 1.1 Prerequisites

1. You must obtain the User ID from SAP Cloud and set your password. These values will be used when you configure the driver using Basic authentication method using the Designer. The procedure to obtain the User ID and setting the password is shown below:

   1. Login to [SAP Identity Authentication Service](https://amynd9qsi.accounts.ondemand.com/saml2/idp/sso?sp=oac.accounts.sap.com&RelayState=https%3A%2F%2Famynd9qsi.accounts.ondemand.com%2Fadmin%2F%23%2Fapplications%2F50c1bb7ce4b01ab0481c49a3%2Ftrust) portal with your credentials.
   2. Navigate to Users & Authorizations > Administrators > SAP Cockpit > Set Password.
   3. Copy and save the User ID value to a convenient location for future use.
   4. Enter the New Password and Re-enter New Password.
   5. Click Save.
2. You need to download and install the SCIM Driver set up files. For more information see, [Installing the SCIM Driver Files and Packages](t4cfey7g8704.html)
3. Update and install the required driver packages. For more information, see [Installing the Driver Packages in Designer](t4cfey7g8704.html#install_driv_packages)
