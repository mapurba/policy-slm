# 5.2 What’s New in Version 4.0.0

This version of the driver provides support for configuring Suite B communication between the Remote Loader and the Identity Manager engine. For more information, see [Authentication](driver-configuration.html#b4jzr84). For more information about Suite B, see [Suite B Cryptography](http://www.nsa.gov/ia/programs/suiteb_cryptography/index.shtml).
