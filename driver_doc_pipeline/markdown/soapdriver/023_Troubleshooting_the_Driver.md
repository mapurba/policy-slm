# 8.0 Troubleshooting the Driver

You can log Identity Manager events by using the Event Auditing Service. Using this service in combination with the driver log level setting provides you with tracking control at a very granular level. For more information, see the [Administrator Guide to NetIQ Identity Reporting](../../../identity-manager-48/report_setup/data/bookinfo.html#bookinfo).
