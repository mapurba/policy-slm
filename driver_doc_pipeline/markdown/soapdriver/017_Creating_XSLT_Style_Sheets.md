# 5.4 Creating XSLT Style Sheets

To enable the SOAP driver to work with any setup other than the default configuration for DSML or SPML, you need to create XSLT style sheets.The application-specific protocol handling is done in Input Transformation and Output Transformation style sheets.

For detailed information on writing style sheets to handle other document types, refer to the sample style sheets that come in the SOAP packages. For more information on style sheets see "[Defining Policies by Using XSLT Style Sheets](../../../identity-manager-48/policy_understanding/data/using-stylesheets-to-define-identity-manager-policies.html#using-stylesheets-to-define-identity-manager-policies)" in the [NetIQ Identity Manager Understanding Policies Guide](../../../identity-manager-48/policy_understanding/data/netiq-identity-manager-policy-understanding.html#netiq-identity-manager-policy-understanding).
