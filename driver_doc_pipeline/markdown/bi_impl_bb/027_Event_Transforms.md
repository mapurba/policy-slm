# A.1 Event Transforms

#### NTIQBBRTDC-sub-evt-VetoRenameEvents

*Description:*
Veto rename events.

#### NTIQBBRTDC-sub-evt-DetermineBBObjectType

*Description:*
Set an operation property name "BBObjectType" that helps map the operation to the type of Blackboard object. Group objects can represent Blackboard Courses or Organizations so it is necessary to specify which one should be used.
