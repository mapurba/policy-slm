# 3.0 Creating a New Driver

After the driver files are installed on the Blackboard system where you want to run the driver (see [Section 2.0, Installing the Driver For Your Blackboard System](b3r8si5.html)), you can create the driver’s representation in the Identity Vault. You do so by importing the basic driver configuration file and then modifying the driver configuration to suit your environment. The following sections provide instructions:

* [Establishing a Security-Equivalent User](saddsa.html)
* [Creating the Driver in Designer](btvlznh.html)
* [Activating the Driver](btvmav1.html)
