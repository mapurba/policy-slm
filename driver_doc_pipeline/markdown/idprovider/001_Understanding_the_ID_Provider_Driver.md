# 1.0 Understanding the ID Provider Driver

The Identity Manager driver for ID Provider enables you to create and maintain a central source of unique IDs that can be consumed by client applications or systems. When the driver receives an ID request from a client, it generates an ID based on policies you define, passes it to the client, and then stores it in the Identity Vault.
