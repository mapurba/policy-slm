# 2.0 Installing Driver Files

The ID Provider Driver is a service driver that is included with the base Identity Manager product. The driver is installed when the Identity Manager engine and drivers are installed. For the installation instructions, see "[Understanding the Installation and Configuration Process](../../../identity-manager-48/setup_linux/data/understanding-the-install-and-configure-process.html#understanding-the-install-and-configure-process)" in the [NetIQ Identity Manager Setup Guide for Linux](../../../identity-manager-48/setup_linux/data/front.html#front) or "[Planning Your Installation](../../../identity-manager-48/setup_windows/data/planning-an-identity-manager-installation.html#planning-an-identity-manager-installation)" in the [NetIQ Identity Manager Setup Guide for Windows](../../../identity-manager-48/setup_windows/data/front.html#front).
