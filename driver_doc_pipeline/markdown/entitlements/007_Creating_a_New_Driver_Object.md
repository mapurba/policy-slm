# 4.0 Creating a New Driver Object

After the Entitlement Service driver files are installed on the server where you want to run the driver (see [Section 3.0, Installing the Driver Files](install-driver-files.html)), you can create the driver object in the Identity Vault. You do so by importing the driver packages and then modifying the driver configuration to suit your environment.

* [Creating the Driver Object in Designer](create-driver-object-designer.html)
* [Activating the Driver](activate-driver.html)
* [Adding Packages to an Existing Driver](add-package-existing-driver.html)
