# 1.0 Understanding the ServiceNow Driver

The NetIQ Identity Manager driver for ServiceNow can seamlessly provision and de-provision users to the ServiceNow cloud application. ServiceNow provides cloud based services that allow users to manage the software through a web service.

The ServiceNow driver supports the following features:

* Supports provisioning users and groups from the Identity Vault
* Supports password synchronization from the Identity Vault
* Supports the creation of user accounts based on policies and entitlements

*IMPORTANT:*The ServiceNow driver is a Subscriber channel only driver.
