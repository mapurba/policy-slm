# 6.1 Starting and Stopping the Driver

To start the driver:

1. In NetIQÂ® iManager, navigate to the Driver Overview for the driver.
2. Click the upper right corner of the driver icon.
3. Click Start driver.

To stop the driver:

1. In iManager, navigate to the Driver Overview for the driver.
