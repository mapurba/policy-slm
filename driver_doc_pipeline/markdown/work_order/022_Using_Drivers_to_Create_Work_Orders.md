# 7.1 Using Drivers to Create Work Orders

Identity Manager drivers can create work orders as a result of events processed by the drivers. For example, if you use a Human Resource driver (SAP, PeopleSoft, and so forth), you can have the driver generate a work order whenever a new user is added. [Section 6.0, Customizing the Driver](customize-driver.html) provides examples of how to use a driver to create a work order.
