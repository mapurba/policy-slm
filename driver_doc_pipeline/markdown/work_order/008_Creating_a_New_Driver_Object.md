# 4.0 Creating a New Driver Object

After the WorkOrder driver files are installed on the server where you want to run the driver (see [Section 3.0, Installing Driver Files](work-order-install-driver-files.html)), you can create the driver in the Identity Vault. You do so by installing the driver packages and then modifying the driver configuration to suit your environment. The following sections provide instructions:

* [Creating the WorkOrder Container in the Identity Vault](create-workorder-container-identity-vault.html)
* [Creating the Driver Object in Designer](create-driver-object-designer.html)
* [Activating the Driver](activate-driver.html)
* [Adding Packages to an Existing Driver](add-package-existing-driver.html)
