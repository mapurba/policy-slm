# 2.1 Plan Your Installation

Prior to installing the driver, ensure all the prerequisites and system versions are updated as shown below:

* Prerequisites:

  + Designer version: IDM 4.8.1.1
  + Install REST driver: REST 1.3.0 or later. For more information see, [Installing the REST Driver Files](../../generic_rest/data/install-rest-driver-files.html#install-rest-driver-files).
* System Requirements:

  + Identity Manager 4.9, or later
