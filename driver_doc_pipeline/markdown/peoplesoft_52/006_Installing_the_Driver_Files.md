# 2.0 Installing the Driver Files

By default, the PeopleSoft driver files are installed on the Identity Manager server at the same time as the Identity Manager engine. The installation program extends the Identity Vault’s schema and installs the driver shim and the driver configuration file. It does not create the driver in the Identity Vault (see [Section 4.0, Creating a New Driver Object](create-driver-object.html)) or upgrade an existing driver’s configuration (see [Section 5.0, Upgrading an Existing Driver](upgrade-existing-driver.html)).

To ensure that you have the driver installed in the right location, and to finish the installation by manually copying required PeopleSoft files to the driver’s directory, refer to the following sections:

* [Installing the Driver Files](bgbi96t.html)
* [Installing the PeopleSoft Components](install-driver-components.html)
* [Copying the PeopleSoft Middleware Library File (psjoa.jar) to the Driver Directory](copy-library-file-to-driver-directory.html)
