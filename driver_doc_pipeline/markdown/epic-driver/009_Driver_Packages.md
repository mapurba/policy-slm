# 2.4 Driver Packages

The following driver packages are utilized by the Epic driver when configured for EMP support:

| Package Name | Min Version | Description |
| CPRS Common | 1.0 | Provides low-level functionality like skipping schema mapping for query results for certain CPRS queries. |
| Custom Entitlements | 1.0 | Provides support for making the custom entitlements available for RBPM (IDM Catalog), by adding them to the entitlement configuration object during driver start. |
| Epic Base | 3.0 | Epic driver base package. |
| Epic EMP Default Configuration | 3.0 | Default EMP configuration parameters and policies. Only use when the driver is managing EMP records. |
| Epic EMP Entitlements | 3.0 | Support for EMP entitlements. Only use when the driver is managing EMP records. |
| Password Synchronization Common | 2.1 | Support for password synchronization. Only use when the driver is managing passwords. |
