# F.2 Global Configuration Values (GCVs)

The management of the provider address fields is configured in the SER Default Configuration GCVs. If the providers in the organization only have a single address, the GCV for "Do providers have a single location or multiple locations" (pdsepicsdcfg.address.type) should be set to "Single." If providers could have multiple locations the GCV should be set to "Multiple."
