# 2.1 Checklist for Installing and Configuring the Driver

Before beginning the installation and configuration process, NetIQ recommends that you review the following steps:

|  | Checklist Items |
| ![](/documentation/docui_b/images/checkcell.png) | 1. Review the considerations for installing and configuring the Entity Data Model driver. For more information, see [Information Needed for Installation and Configuration](b1eqmb17.html#b1fiys8m). |
| ![](/documentation/docui_b/images/checkcell.png) | 2. Ensure that your environment meets the requirements for installing and configuring the Entity Data Model driver. For more information, see [Planning to Install and Configure the Driver](b1eqmb17.html). |
| ![](/documentation/docui_b/images/checkcell.png) | 3. Install the Remote Loader and the driver files on the Entity Data Model server. For more information, see [Installing the Remote Loader and Driver Files](b1fixbz2.html). |
| ![](/documentation/docui_b/images/checkcell.png) | 4. Ensure that the Entity Data Model driver can perform provisioning tasks in the identity applications. For more information, see [Creating an Identity Manager Provisioning Service Account for the Driver](b1fdqy55.html). |
| ![](/documentation/docui_b/images/checkcell.png) | 5. Ensure that you have the appropriate packages installed and imported for the Entity Data Model driver, User Application driver, and notifications object in Designer. For more information, see [Updating the Base Package for the Entity Data Model Driver](b1fiyn6y.html#b1fixugi). |
| ![](/documentation/docui_b/images/checkcell.png) | 6. Configure the basic settings for the Entity Data Model driver. For more information, see [Configuring the Entity Data Model Driver](b1fiyn6y.html#b1eq64sa). |
| ![](/documentation/docui_b/images/checkcell.png) | 7. Apply the system account that you created in the identity application for the driver. For more information, see [Adding the Driver Account to the Entity Data Model Driver](b1fiyn6y.html#b1fj1du0). |
| ![](/documentation/docui_b/images/checkcell.png) | 8. Deploy the updated Entity Data Model driver, User Application driver, and notifications object. For more information, see [Deploying the Entity Data Model Driver and Supporting Objects](b1fiyn6y.html#b1eq64sd). |
| ![](/documentation/docui_b/images/checkcell.png) | 9. Ensure that Entity Data Model can integrate collected permissions and permission assignment tasks with the role and resource catalog in Identity Manager. For more information, see [Configuring Entity Data Model](b1fiz4wa.html). |
