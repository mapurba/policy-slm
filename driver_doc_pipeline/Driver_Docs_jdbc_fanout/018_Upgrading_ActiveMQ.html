2.8 Upgrading ActiveMQ

  1. Download the ActiveMQ <version> from the ActiveMQ Download page.

  2. Extract the file to a preferred location on your computer.

  3. Stop the Fanout Agent. For more information, see Stopping the Fanout Agent.

  4. Copy the extracted file to your Identity Manager and Fanout Agent installation directories.

    For example, /opt/novell/eDirectory/lib/dirxml/classes/ or C:\NetIQ\IdentityManager\NDS\lib directory for Identity Manager installation and /opt/novell/dirxml/fanoutagent/lib or C:\NetIQ\IdentityManager\FanoutAgent\lib directory for Fanout agent installation.

  5. Start the Fanout Agent. For more information, see Starting the Fanout Agent.
