1.0 Introduction

Novell GroupWise is a cross-platform, corporate email system that provides secure messaging, calendaring, and scheduling. GroupWise also includes task management, contact management, document management, and other productivity tools that are secure, highly available, and easily accessible. For more information, visit GroupWise Documentation website.
