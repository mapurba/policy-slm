6.0 Upgrading an Existing Driver

For upgrading the driver packages, see the respective readme. Before upgrading your driver packages, ensure to perform the following actions:

  • Backup the driver configuration by using the designer driver export.

  • Backup the driver customizations such as driver configuration, GCVs, policies etc. from designer for post package upgrade and review.

  • Follow package upgrade instructions and review GCVs / driver configuration settings in designer prior to reconcile to the Identity Vault.
