2.0 Installing and Configuring the Workday Driver

This section contains information about installing and configuring the Workday driver.

The installation and configuration process for the driver varies depending on whether you want to install the driver with the Identity Manager server or with the Remote Loader. After installing the driver, you must manually activate it. For more information, see Activating the Driver.
