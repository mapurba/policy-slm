A.2 Global Configuration Values

There are no predefined global configuration values (GCVs) specific to the Entitlements Service driver. As with all drivers, you can add GCVs that you need.

In Identity Console:

  1. Click the IDM Administration tile.

  2. Select the driver set that contains the driver whose properties you want to edit.

  3. Locate the driver icon, then click the driver icon to display the driverâs properties page.

  4. Click Global Config Values drop down to display the GCV page.

In Designer:

  1. Open a project in the Modeler.

  2. Right-click the driver icon or line, then select Properties > Global Configuration Values.
