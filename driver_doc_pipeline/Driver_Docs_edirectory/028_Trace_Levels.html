C.0 Trace Levels

The driver supports the following trace levels:

Table C-1 Supported Trace Levels

Level

Description

0

No trace messages are displayed or logged

1-2

Basic trace messages like driver start/stop and documents sent/received are displayed and logged

3-12

Trace Level 1-2 messages are displayed and logged, as well as some additional informative messages

13

Trace Level 1-12 messages are displayed and logged, as well as in-depth details of messages received through the Publisher channel
