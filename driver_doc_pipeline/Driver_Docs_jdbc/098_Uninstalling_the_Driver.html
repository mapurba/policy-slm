A.0 Uninstalling the Driver

  • Deleting Identity Manager Driver Objects

  • Running the Product Uninstaller

  • Executing Database Uninstallation Scripts

NetIQ Corporation recommends that you install and uninstall preconfigured drivers and database scripts as a unit. To prevent unintentional mismatching, database scripts and preconfigured drivers contain headers with a version number, the target database name, and the database version.
